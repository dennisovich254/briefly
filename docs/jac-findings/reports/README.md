# Evaluation reports

Reports of the Jac evaluation (architecture §21.7):

- `baseline-<version>.md` after phase 1 (the architecture's phase 0)
- `phase-<n>.md` after each later phase
- `release-<version>.md` after each compiler upgrade
- `final.md` after phase 6

Each report gives the capability-matrix verdicts and what changed since the last report; new, fixed and still-open findings; the measurement table compared with the previous one; and any profile decision taken.
